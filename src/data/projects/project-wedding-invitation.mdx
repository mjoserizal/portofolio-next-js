# Introduction

A beautiful and elegant wedding invitation website featuring interactive sections including RSVP confirmation, photo gallery, countdown timer, wishes board, and digital gift through Saweria.

## Features

- Elegant landing page with smooth animations
- Couple story timeline
- Wedding event details with Google Maps integration
- Photo gallery with lightbox
- RSVP confirmation form
- Wishes & prayers section
- Digital gift envelope via Saweria
- Responsive design for all devices
